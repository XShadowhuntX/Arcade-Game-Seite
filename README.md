# 🚀 Space Neon Arcade

Eine **Arcade-Webseite im Neon-Weltraum-Stil** mit mehreren spielbaren Mini-Games direkt im Browser.

Die Seite kombiniert **HTML, CSS und JavaScript**, um eine animierte Space-Umgebung mit Arcade-Look zu erzeugen.
Dazu gehören Sternenfelder, Sternschnuppen, Parallax-Scrolling und ein Konfetti-Effekt bei Gewinnen.

---

# ▶️ Nutzung / Installation

## Repository klonen

```bash
git clone https://github.com/DEINNAME/REPOSITORYNAME.git
```

## In den Projektordner wechseln

```bash
cd REPOSITORYNAME
```

## Webseite starten

Einfach die Datei **index.html** öffnen:

```bash
xdg-open index.html
```

Oder im Dateimanager doppelklicken.

Die Seite läuft komplett **lokal im Browser**, es wird kein Server benötigt.

---

## 🎮 Spiele

Die Webseite enthält mehrere Mini-Games:

### 🪐 Hangman

Errate das versteckte Wort Buchstabe für Buchstabe.

Features:

* Virtuelle Tastatur
* Anzeige falscher Versuche
* Konfetti bei Gewinn
* ASCII-Hangman Zeichnung

---

### ❌⭕ Tic Tac Toe

Klassisches Tic-Tac-Toe für **2 Spieler**.

Features:

* Spieler X gegen Spieler O
* Gewinnererkennung
* Neustart-Button

---

### 🧠 Memory

Finde die passenden Kartenpaare.

Features:

* 16 Karten
* Zug-Zähler
* Anzeige gefundener Paare
* Automatisches Zurückdrehen falscher Karten

---

### 🐍 Snake

Steuere eine Schlange und sammle Punkte.

Features:

* Steuerung mit **Pfeiltasten oder WASD**
* Score-Anzeige
* Game Over bei Kollision

---
